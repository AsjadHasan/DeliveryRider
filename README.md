# DeliveryRider
A food delivery startup has two types of riders: bicycle riders and motorbike riders. The dispatcher enters each rider's type, name, and how many deliveries they've made today into the terminal, and the program calculates their pay.
<br>
Topics Covered:
<br>
1. Classes and Objects
2. Inheritance
3. Parent and Child Classes
4. Constructor (__init__)
5. Method Overriding
6. superclass and subclass concepts
7. while Loop
8. User Input
9. Conditional Statements
10. Exception Handling (try-except)
11. Lists and for Loops
12. Docstrings
